Drop a looping soundtrack here as:  music.mp3

- If music.mp3 exists, the game plays it (looped) instead of the
  built-in procedural synthwave track.
- Set MUSIC_BPM in js/config.js to your track's tempo so the
  visual beat pulses stay in sync.
- Note: loading local files requires serving the game over HTTP
  (see the project README). When opened via file://, the game
  always uses the procedural soundtrack.
